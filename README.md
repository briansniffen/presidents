# Presidents Flashcards

Spaced-repetition flashcards for the 47 presidencies of the United States: years on the front; name, party, predecessor and successor on the back.

- Starts with presidencies #1–5 and adds 5 more at a time.
- Correct cards come back after 1, 3, 7, 16 and 35 days; missed cards repeat right away.
- "Practice a group" drills any range in shuffled order without touching the schedule.
- Progress is stored on the device (no account). "Move progress to another device" copies a backup code.
- Works offline and can be added to a phone's home screen.

Plain static files; no build step. Serve the folder with GitHub Pages or any static host.
